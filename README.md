# Модель лесного пожара

## Описание модели

Модель лесного пожара — это двумерный клеточный автомат, предназначенный для качественного исследования распространения огня в неоднородной среде, а также процессов роста и восстановления леса.

Пространство представляет собой регулярную квадратную решётку размером \(m \times n\).  
Время дискретно: состояния всех клеток обновляются синхронно на каждом такте.

Модель является стохастической: часть переходов задаётся вероятностями.

## Состояния клетки

Каждая клетка может находиться в одном из трёх состояний:

| Состояние | Обозначение | Смысл |
|-----------|-------------|-------|
| `0` | `EMPTY` | пустая клетка или сгоревшее дерево |
| `1` | `TREE` | клетка с деревом |
| `2` | `BURNING` | горящее дерево |

## Окрестность

По умолчанию используется окрестность Мура — 8 соседей.  
Также может быть выбрана окрестность фон Неймана — 4 соседа.

## Правила обновления

Обновление происходит синхронно: новое состояние каждой клетки вычисляется на основе состояния поля на предыдущем шаге.

1. **Горящее дерево** (`BURNING`) на следующем шаге становится **пустой клеткой** (`EMPTY`).

2. **Дерево** (`TREE`) загорается, если:
   - в его окрестности находится не меньше \(k\) горящих деревьев;
   - или с вероятностью \(f\) происходит удар молнии.

3. **Пустая клетка** (`EMPTY`) с вероятностью \(p\) зарастает новым деревом (`TREE`), если в её окрестности нет ни одного горящего дерева.

4. **Граничные условия:** обычно фиксированные — за пределами поля деревьев нет.  
   Другие типы границ (периодические, отражающие) могут быть заданы отдельно.

## Параметры модели

| Параметр | Обозначение | Смысл |
|----------|-------------|-------|
| Размер поля | `m`, `n` | число строк и столбцов решётки |
| Вероятность зарастания | `p` | вероятность появления дерева на пустой клетке |
| Вероятность молнии | `f` | вероятность самовозгорания дерева |
| Порог заражения огнём | `k` | минимальное число горящих соседей для воспламенения |
| Окрестность | `neighborhood` | 4 (фон Нейман) или 8 (Мур) |
| Начальная плотность леса | `tree_prob` | доля клеток с деревьями в начальном состоянии |
| Число шагов | `steps` | количество итераций моделирования |

## Характеристики модели

- **Дискретность:** пространство, время и состояния клеток дискретны.
- **Локальность:** состояние клетки зависит только от её окрестности.
- **Однородность:** правила одинаковы для всех клеток.
- **Стохастичность:** присутствуют вероятностные события (молния, рост дерева).
- **Синхронность:** все клетки обновляются одновременно.
- **Эмерджентность:** глобальные структуры (фронт пожара, самоорганизованная критичность) возникают из простых локальных правил.
- **Отсутствие центрального управления:** динамика определяется только локальными взаимодействиями.

## Ограничения модели

- Не учитывает направление и силу ветра.
- Не учитывает влажность, температуру, рельеф местности.
- Не различает типы деревьев и их горючесть.
- Не моделирует теплопередачу, конвекцию и дым.
- Использует фиксированные или упрощённые граничные условия.
- Не является точной физической моделью реального лесного пожара.
- Результаты сильно зависят от начального распределения и вероятностных параметров.
- Синхронное обновление может приводить к артефактам, которых нет в непрерывных моделях.

# Описание программы

## Назначение

Программа реализует описанную выше модель лесного пожара на языке Python и позволяет:

- запускать симуляцию на заданное число шагов;
- визуализировать эволюцию поля в режиме реального времени с помощью `matplotlib.animation`;
- собирать статистику по ходу симуляции (число пустых клеток, деревьев, горящих деревьев, число выросших и сгоревших деревьев);
- сохранять начальное и конечное состояния поля в виде PNG-файлов;
- выводить итоговую сводку эксперимента в консоль.

## Структура программы

Программа состоит из нескольких логических блоков:

1. **Константы состояний**  
   `EMPTY = 0`, `TREE = 1`, `BURNING = 2`.

2. **Параметры модели**  
   Размер поля, вероятности `p` и `f`, порог `k`, тип окрестности, число шагов, `seed` для воспроизводимости.

3. **Функции модели:**
   - `init_forest(rows, cols, tree_prob, seed)` — создаёт начальное поле со случайным распределением деревьев;
   - `count_burning_neighbors(grid, i, j, neighborhood)` — подсчитывает число горящих соседей у клетки;
   - `step(grid, p, f, k, neighborhood)` — выполняет один шаг модели;
   - `count_states(grid)` — возвращает словарь с числом пустых, древесных и горящих клеток;
   - `format_stats_text(...)` — формирует текст статистики для отображения на графике.

4. **Инициализация поля и счётчиков**  
   Создаётся поле, словарь `stats` с накопительными счётчиками и историей по шагам.

5. **Визуализация**  
   Создаётся фигура `matplotlib`, на ней отображается поле через `imshow`, добавляются заголовок, цветовая шкала и текстовый блок статистики.

6. **Сохранение начального состояния**  
   До запуска анимации вызывается `fig.savefig('forest_fire_initial.png', ...)`.

7. **Функция обновления кадра `update(frame)`**  
   - выполняет один шаг модели;
   - сравнивает предыдущее и текущее поля, чтобы посчитать, сколько деревьев выросло и сгорело за шаг;
   - обновляет накопительные счётчики и историю;
   - обновляет изображение поля, заголовок и текст статистики.

8. **Запуск анимации**  
   `FuncAnimation(fig, update, frames=STEPS, interval=50, blit=False, repeat=False, cache_frame_data=False)`.

9. **Сохранение конечного состояния**  
   После закрытия окна анимации вызывается `fig.savefig('forest_fire_final.png', ...)`.

10. **Итоговая сводка**  
    В консоль печатается таблица с параметрами эксперимента, финальным распределением состояний и накопленными счётчиками.

## Выходные файлы

| Файл | Содержимое |
|------|------------|
| `forest_fire_initial.png` | Изображение начального состояния поля и панели статистики |
| `forest_fire_final.png` | Изображение конечного состояния поля и итоговой панели статистики |

Оба файла сохраняются в текущей рабочей директории с разрешением 150 dpi.

## Что выводится в консоль

- сообщение о сохранении начального PNG;
- сообщение о сохранении конечного PNG;
- таблица с итогами эксперимента:
  - параметры модели;
  - финальное распределение состояний (пусто / деревья / горит) в абсолютных числах и процентах;
  - суммарное число выросших и сгоревших деревьев за всю симуляцию.

## Что отображается на графике

- поле клеток: чёрный — пусто, зелёный — дерево, красный — огонь;
- заголовок с текущим номером шага;
- цветовая шкала с подписями состояний;
- текстовый блок в левом верхнем углу:
  - текущий шаг;
  - доля и число пустых клеток, деревьев и горящих деревьев;
  - сколько деревьев выросло и сгорело на текущем шаге;
  - сколько всего деревьев выросло и сгорело за симуляцию.
